KNOWLEDGE CENTRE ADMIN

GitHub Admin

The Knowledge Centre stays entirely on GitHub Pages. Administrative access is controlled by your GitHub account and repository permissions.

Open GitHub Admin Sign in to GitHub if required, then use the repository's Actions and content controls. Knowledge Control Centre Open the KKA publishing control panel and links to the protected GitHub editing workflow.

No password, OTP seed, GitHub token or session credential is stored in this public page. GitHub itself performs authentication and authorization. The existing File Server administration remains completely separate.
